# 📧 Email Unsubscriber

Μικρό πρόγραμμα που σαρώνει το e-mail σου, βρίσκει τα **διαφημιστικά / newsletter
που σου έρχονται ακόμα** και σε αφήνει να διαλέξεις από ποια θα κάνεις **unsubscribe**.

- Δεν χρειάζεται εγκατάσταση βιβλιοθηκών (μόνο Python 3.8+).
- Ανοίγει το γραμματοκιβώτιο **μόνο για ανάγνωση**: δεν σβήνει, δεν μετακινεί και δεν
  σημειώνει τίποτα ως αναγνωσμένο.
- Δουλεύει με Gmail, Outlook/Hotmail, Yahoo, iCloud και κάθε πάροχο με IMAP.

## Πώς βρίσκει τα διαφημιστικά

Κοιτάει τα e-mail των τελευταίων N ημερών (default 60) για το header
`List-Unsubscribe`, που το έχουν όλα τα newsletter (το Gmail και το Yahoo το απαιτούν
από τους μαζικούς αποστολείς). Τα ομαδοποιεί ανά αποστολέα και τα ταξινομεί κατά το
πόσα σου έστειλαν, οπότε στην κορυφή είναι όσοι σε βομβαρδίζουν περισσότερο.

## Πώς κάνει unsubscribe

| Μέθοδος     | Τι κάνει                                                              |
|-------------|-----------------------------------------------------------------------|
| `one-click` | Αυτόματο αίτημα στον αποστολέα (RFC 8058). Ολοκληρώνεται αμέσως.      |
| `e-mail`    | Σου στέλνει αυτόματα ένα e-mail διαγραφής από τον λογαριασμό σου.     |
| `browser`   | Ανοίγει τη σελίδα διαγραφής στον browser για να πατήσεις το κουμπί.   |

Όσους έχεις κάνει unsubscribe τους κρατάει στο `unsubscribed.json`. Αν ξανατρέξεις το
πρόγραμμα και κάποιος συνεχίζει να στέλνει, θα εμφανιστεί με ⚠️.

## Ρύθμιση (Gmail)

1. Ενεργοποίησε την επαλήθευση σε 2 βήματα: https://myaccount.google.com/security
2. Φτιάξε ένα **App Password**: https://myaccount.google.com/apppasswords
   (όνομα π.χ. «Unsubscriber»). Θα σου δώσει έναν κωδικό 16 χαρακτήρων.
3. Χρησιμοποίησε αυτόν τον κωδικό όταν το πρόγραμμα σου ζητήσει password
   (**όχι** τον κανονικό σου κωδικό).

Για Outlook/Yahoo/iCloud η διαδικασία είναι παρόμοια (App Password από τις ρυθμίσεις
ασφαλείας του λογαριασμού).

## Χρήση

```bash
python3 unsubscriber.py
```

Θα σου ζητήσει e-mail και App Password, και μετά θα δεις κάτι σαν:

```
  #  Αποστολέας                         Πλήθος  Τελευταίο   Μέθοδος    Τελευταίο θέμα
---------------------------------------------------------------------------------------
  1  Shop <news@shop.gr>                    24  31/10/2026  one-click  -50% σε όλα!
  2  Travel <deals@travel.com>              11  30/10/2026  e-mail     Οι προσφορές της εβδομάδας
  3  Blog <hello@blog.io>                    3  28/10/2026  browser    Νέο άρθρο

Διάλεξε από ποιους θέλεις unsubscribe:
  π.χ. 1,3,5-8   ή   all   ή   Enter για έξοδο
>
```

### Επιλογές

```bash
python3 unsubscriber.py --days 30            # μόνο τον τελευταίο μήνα
python3 unsubscriber.py --min-count 3        # μόνο όσους έστειλαν ≥ 3 e-mail
python3 unsubscriber.py --folder "[Gmail]/All Mail"   # όλο το Gmail (μαζί με Προωθήσεις)
python3 unsubscriber.py --dry-run            # δείξε τι θα γινόταν, χωρίς να αλλάξει τίποτα
```

Για να μη γράφεις κάθε φορά τα στοιχεία:

```bash
export EMAIL_USER="you@gmail.com"
export EMAIL_APP_PASSWORD="xxxx xxxx xxxx xxxx"
python3 unsubscriber.py
```

> 💡 Στο Gmail τα διαφημιστικά συνήθως πηγαίνουν στην καρτέλα «Προωθήσεις», που είναι
> μέρος του INBOX, οπότε τα βρίσκει και με τον default φάκελο.
